# devin-repo

Repositório base para os nossos projetos.

Este repositório serve como ponto de partida centralizado para projetos
desenvolvidos em conjunto com o Devin. A ideia é manter aqui uma estrutura
organizada onde novos projetos podem ser adicionados e evoluídos ao longo do
tempo.

## Estrutura

```
.
├── README.md        # Este arquivo
├── .gitignore       # Arquivos e pastas ignorados pelo Git
└── projects/        # Cada subpasta é um projeto independente
```

## Como adicionar um novo projeto

1. Crie uma pasta dentro de `projects/` com o nome do projeto.
2. Adicione um `README.md` próprio descrevendo o projeto.
3. Faça o commit e abra um Pull Request.

## Convenções

- Commits pequenos e descritivos.
- Cada projeto documentado no seu próprio `README.md`.
- Branches de trabalho seguindo o padrão `devin/<descrição>`.
